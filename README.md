Este repositório contém o projeto desenvolvido para a disciplina de **Engenharia de Software I**, focado na aplicação de conceitos e práticas essenciais para o desenvolvimento de software.

## 💻 Tecnologias Utilizadas

O projeto é primariamente implementado em **Java**, utilizando o ecossistema padrão da linguagem para desenvolvimento e testes.

* **Linguagem Principal:** Java
* **Ferramentas de Teste:** JUnit.

## 🚀 Estrutura do Projeto

A estrutura do repositório tem foco em **Testes de Software** e **Verificação de Requisitos**.

| Arquivo/Diretório | Descrição |
| :--- | :--- |
| **`teste-automatizado/`** | Diretório destinado a abrigar os testes automatizados do sistema, como testes de unidade e testes de integração. |
| **`Testando.java`** | Classe principal que pode conter a lógica da aplicação ou exemplos de funcionalidades sendo testadas. |
| **`TestandoRequisitos.java`** | Classe dedicada a testes de requisitos, verificando se o software atende às especificações definidas. |

## 🛠️ Como Executar o Projeto

Para compilar e executar este projeto, você precisará ter o **Java Development Kit (JDK)** instalado em sua máquina.

### 1. Clonar o Repositório

```bash
git clone [https://github.com/Muriloferbhs/Engenharia1.git](https://github.com/Muriloferbhs/Engenharia1.git)
cd Engenharia1
```

### 2. Compile os arquivos java

```bash
javac Testando.java TestandoRequisitos.java
```

### 3. Execute

```bash
java Testando
```
